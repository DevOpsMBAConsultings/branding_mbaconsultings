# branding_mbaconsultings

Modulo `mba_ux_branding` (Odoo 19): iconos de apps en el estandar visual nativo de Odoo.

Estandar de iconos: SVG 50x50, 3 formas planas en 3 tonos de la paleta de Odoo
(`#985184`, `#FBB945`, `#1AD3BB`, `#005E7A`, `#712258`), sin fondo, degradados ni sombras.
PNG de 100x100 generado a partir del SVG.

Estado: sin probar en una instancia de Odoo. Pendiente probar la instalacion y el
cambio de nombre de menu (requiere traduccion es_419).
